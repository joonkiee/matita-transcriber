설치

1분이면 시작해요

Matita는 유료 인증서로 서명하지 않아서, 처음 한 번 컴퓨터가 확인을 요청해요.

/01

받아서 끌어 놓기

.dmg를 열고 Matita를 응용 프로그램 폴더로 끌어다 놓아요.

/02

한 번 열기

macOS가 앱을 확인할 수 없다고 하면 완료를 눌러요.

/03

그래도 열기

시스템 설정 → 개인정보 보호 및 보안에서 그래도 열기를 눌러요. 처음 한 번만 하면 돼요.

터미널이 편하다면: xattr -dr com.apple.quarantine /Applications/Matita.app

/01

설치 파일 실행

내 계정에만 설치돼요. 관리자 암호가 필요 없어요.

/02

Windows가 경고하면

“Windows의 PC 보호” 창에서 추가 정보를 누르고 실행을 눌러요.

/03

Matita 열기

시작 메뉴에서 열어요. 별도 창으로 열리고, 창을 닫으면 Matita도 종료돼요.

64비트 Windows 10 또는 11이 필요해요. 그래픽카드 드라이버가 Vulkan을 지원하면 그래픽카드로, 아니면 CPU로 받아써요(더 느려요).

FAQ

자주 묻는 질문

컴퓨터 밖으로 나가는 게 있나요?

녹음과 받아쓴 글은 나가지 않아요. 처음 음성 모델을 내려받을 때, GitHub에서 새 버전을 확인할 때, 그리고 요약에 Claude를 고른 경우 글을 Anthropic에 보낼 때만 인터넷을 써요.

용량은 얼마나 필요한가요?

앱은 약 100 MB이고, 처음 쓸 때 음성 모델 하나를 내려받아요: 640 MB(Parakeet), 870 MB(Turbo 8-bit), 1.6 GB(Turbo). 한국어는 Turbo를 쓰세요.

어떤 컴퓨터에서 되나요?

Apple Silicon(M1 이상) Mac과 macOS 14 Sonoma 이상, 그리고 64비트 Windows 10·11(베타)에서 돼요. 인텔 Mac은 지원하지 않아요. 통화 상대방 목소리 녹음(macOS 14.2 이상 필요)과 아이폰 음성 메모는 지금은 Mac에서만 돼요.

처음 열 때 왜 경고가 뜨나요?

유료 인증서로 서명하지 않은 앱이면 macOS와 Windows가 항상 이 경고를 보여줘요. Matita는 소스 코드가 공개되어 있고, 모든 버전을 GitHub에서 그 코드로 빌드해요.

삭제는 어떻게 하나요?

Mac: Matita를 종료하고 휴지통으로 끌어다 놓으세요. 모델은 ~/whisper-models, 설정은 ~/whisper-app에 있어요. Windows: 설정 → 앱 → Matita → 제거. 모델과 설정은 %LOCALAPPDATA%\Matita에 있어요. 받아쓴 글은 Transcripts 폴더에 그대로 남아요.

어떻게 도울 수 있나요?

GitHub에 문제나 아이디어를 남기거나 별(Star)을 눌러 주세요.
